STUDI KASUS / TEAM WORKFLOW · FULL STACK

DevTrack.

Kerja tim,
dari tugas sampai review.

Workspace proyek untuk membagi tugas, mengirim hasil kerja, meminta revisi, dan menyelesaikan pekerjaan setelah disetujui reviewer.

  • React
  • TypeScript
  • Express
  • Prisma
  • PostgreSQL
  • Socket.IO

01 / KONTEKS

Masalah yang
dipecahkan.

Pekerjaan tim sering tersebar di daftar tugas dan percakapan. Penanggung jawab, reviewer, serta manajer membutuhkan status dan riwayat keputusan yang jelas dalam satu workspace.

02 / PRODUK

Lihat alurnya,
langkah demi langkah.

Manajer membuat tugas dan memilih penanggung jawab serta reviewer → developer menyelesaikan checklist dan mengirim hasil → reviewer menyetujui atau meminta revisi → tugas selesai atau kembali dikerjakan.

03 / DI BALIK LAYAR

Yang membuatnya
bekerja.

01

Keputusan teknis

React dan TypeScript membangun antarmuka; Express dan Zod menangani API serta validasi. Prisma dan PostgreSQL menyimpan tugas, versi pengajuan, dan aktivitas. Transaksi serializable serta pemeriksaan versi mencegah perubahan lama menimpa pekerjaan terbaru; Socket.IO memberi sinyal pembaruan.

02

Catatan demo

Demo memakai workspace dan data fiktif yang terpisah untuk tiap pengunjung selama 24 jam. Demo tidak dapat mengirim undangan; pengunjung bisa berganti peran untuk mencoba alur review.
